1Comment fonctionne l'appel

Vous n'avez plus d'appel à faire : chaque étudiant passe sa carte étudiante sur le boîtier en entrant dans la salle. Le site rattache automatiquement chaque bip à votre cours (celui de l'emploi du temps à cette heure-là) et calcule le statut :

Présentbadge avant le début du cours + {{ TOLERANCE_RETARD_MIN }} min
En retardbadge plus tard pendant le cours
Absentaucun badge

Le boîtier accepte les badges dès 15 min avant le début du cours. Il fonctionne même sans réseau : les bips sont gardés et envoyés dès que la connexion revient.

2Se connecter

{% call etape(1, "Ouvrir le site") %}

Dans votre navigateur, ouvrez l'adresse donnée par l'administrateur (par exemple http://pointage.iut.local:8000).

{% endcall %} {% call etape(2, "Saisir vos identifiants") %}

Entrez l'identifiant et le mot de passe que l'administrateur vous a créés, puis cliquez sur {{ bouton("Se connecter") }}.

Vous restez connecté tant qu'une page du site est ouverte. Après un long moment d'inactivité, le site vous redemande votre mot de passe.

{% endcall %}

3Retrouver ses cours

Après la connexion, vous arrivez sur Mes cours : votre emploi du temps de la semaine, importé depuis ADE.

{{ capture("e-mes-cours", "Mes cours : chaque cours affiche le nombre de présents sur le nombre d'inscrits.") }}
  • Les flèches changent de semaine, {{ bouton("Aujourd'hui") }} revient à la semaine en cours.
  • Sur chaque cours : présents / inscrits. Un cours où personne n'a badgé est grisé : il ne compte pas dans les absences (boîtier oublié ou éteint).

4Suivre l'appel en direct

{% call etape(1, "Cliquer sur le cours") %}

La feuille d'émargement s'ouvre sur le côté. Elle se met à jour toute seule pendant que les étudiants badgent.

{{ capture("e-emargement", "La feuille d'émargement : statut, heure d'arrivée et de sortie de chaque étudiant.") }} {% endcall %} {% call etape(2, "Lire la feuille") %}
  • Arrivée : heure du premier badge. Sortie : heure du dernier badge (si l'étudiant rebadge en partant).
  • barrée : l'étudiant n'a pas encore de carte associée, il ne peut pas badger. Signalez-le au secrétariat.
  • L'icône ouvre la feuille en pleine page (pratique pour la projeter).
{% endcall %}

5Corriger un statut à la main

Un étudiant a oublié sa carte, le boîtier était en panne ? Vous pouvez valider sa présence vous-même.

{% call etape(1, "Cliquer sur le statut de l'étudiant") %}

Un menu Valider à la main s'ouvre.

{{ capture("e-valider-main", "Le menu « Valider à la main » sur le statut d'un étudiant.") }} {% endcall %} {% call etape(2, "Choisir le bon statut") %}

{{ bouton("Présent", "check-circle") }} {{ bouton("En retard", "clock-history") }} ou {{ bouton("Absent", "x-circle") }}. Le statut est marqué d'une petite main : on sait qu'il a été validé à la main.

{% endcall %} {% call etape(3, "Annuler si besoin") %}

{{ bouton("Revenir au badge", "arrow-counterclockwise") }} efface votre correction : le statut redevient celui calculé à partir des badges.

{% endcall %}

6Exporter la feuille d'émargement

Le bouton {{ bouton("Excel", "file-earmark-excel") }} en haut de la feuille télécharge la liste du cours (étudiant, arrivée, sortie, statut) : à garder comme justificatif ou à transmettre au secrétariat.

7Le boîtier : signaux et bons gestes

{% call etape(1, "En arrivant : brancher le boîtier") %}

Branchez-le sur une prise ou un port USB. Il est prêt en une vingtaine de secondes, quand la LED bleue reste allumée.

{% endcall %} {% call etape(2, "Les étudiants badgent") %}

Chaque étudiant pose sa carte à plat sur le boîtier, environ une seconde. Le boîtier est prêt pour la carte suivante en moins d'une seconde.

{% endcall %}
SignalCe que ça veut direQue faire
bleue fixeprêt, serveur joignablerien

bleue qui clignote lentementpas de réseaucontinuer normalement : les bips sont gardés et partiront plus tard
bleue qui clignote viteenvoi des bips au serveurrien
rouge qui clignote 3 sle programme a redémarré après une erreurattendre la LED bleue ; si ça se répète, prévenir l'administrateur
{% call encadre("attention", "Débrancher le boîtier") %}

Vous pouvez le débrancher à la fin du cours sans précaution particulière : chaque badge est enregistré sur le boîtier dès qu'il est lu et n'est effacé qu'une fois reçu par le serveur.

{% endcall %}

8Questions fréquentes

{% call encadre("panne", "Un étudiant dit avoir badgé mais il apparaît absent") %}

Vérifiez la LED bleue : si elle clignote lentement, le boîtier n'a pas encore pu envoyer les bips (ils arriveront au retour du réseau). Sinon, sa carte n'est peut-être associée à personne : validez-le à la main et prévenez le secrétariat.

{% endcall %} {% call encadre("panne", "Mon cours n'apparaît pas ou est à la mauvaise heure") %}

L'emploi du temps vient d'ADE. Demandez au secrétariat de cliquer sur « Synchroniser l'EDT ».

{% endcall %} {% call encadre("panne", "J'ai oublié mon boîtier") %}

Validez les étudiants à la main depuis la feuille d'émargement (section 5). Le cours ne sera pas compté comme « personne n'a badgé ».

{% endcall %} {% call encadre("astuce", "Mot de passe oublié") %}

Demandez à l'administrateur : il vous en définit un nouveau dans la page Professeurs.

{% endcall %}
