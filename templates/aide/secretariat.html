1Le tableau de bord

C'est la première page après la connexion (identifiant administrateur). Elle résume la journée :

{{ capture("s-tableau-de-bord", "Le tableau de bord : cours du jour, taux de présence, boîtiers en ligne, étudiants à risque.") }}
  • Cours du jour avec le nombre de présents ; un cours où personne n'a badgé est signalé (boîtier oublié ou éteint).
  • Présence sur les 7 derniers jours et boîtiers en ligne (un boîtier hors ligne n'a pas contacté le serveur récemment).
  • Étudiants à risque : sous {{ SEUIL_RISQUE }} % de présence, les absences justifiées n'étant pas comptées.

2Importer la liste des étudiants

{% call etape(1, "Ouvrir la page Étudiants") %}

Menu Étudiants, puis {{ bouton("Importer un fichier Excel", "file-earmark-arrow-up") }}.

{{ capture("s-import", "La fenêtre d'import et les deux formats de fichier acceptés.") }} {% endcall %} {% call etape(2, "Choisir le fichier") %}

Deux formats sont acceptés (la première ligne contient les titres de colonnes) :

  • Liste de la scolarité : NOM, PRENOM, PARCOURS, ANNEE, TD, TP. Sans numéro étudiant : un numéro provisoire (PROV-…) est donné, puis remplacé par le vrai au prochain import qui le contient.
  • Fichier simple : numero, nom, prenom, groupe.
{% endcall %} {% call etape(3, "Cliquer sur Importer") %}

Un message indique combien d'étudiants ont été ajoutés et mis à jour. Réimporter le même fichier ne crée pas de doublons : un étudiant déjà connu (même numéro, ou même nom et prénom) est mis à jour, ses groupes sont remplacés par ceux du fichier.

{% endcall %} {% call encadre("astuce", "Ajouter un étudiant arrivé en cours d'année") %}

Bouton {{ bouton("Ajouter", "person-plus") }} de la page Étudiants : un formulaire suffit, pas besoin de refaire un import.

{% endcall %}

3Associer les cartes étudiantes

Un étudiant ne peut badger qu'une fois sa carte associée à son nom. L'association se fait une seule fois, en début d'année.

{% call etape(1, "Repérer les étudiants sans carte") %}

Cochez le filtre Sans carte puis {{ bouton("Filtrer") }}.

{{ capture("s-etudiants", "La liste des étudiants : groupe, taux de présence et état de la carte de chacun.") }} {% endcall %} {% call etape(2, "Cliquer sur « Scanner la carte »") %}

Sur la ligne de l'étudiant, {{ bouton("Scanner la carte", "upc-scan") }}. Une fenêtre attend la carte.

{{ capture("s-scan", "La fenêtre « Passez la carte sur le boîtier ».") }} {% endcall %} {% call etape(3, "Passer la carte sur le boîtier d'accueil") %}

L'étudiant pose sa carte sur le boîtier d'accueil (celui du secrétariat). Le boîtier fait vert + bleu et la fenêtre affiche Carte détectée : c'est fait. Passez à l'étudiant suivant.

{% endcall %} {% call encadre("attention", "« Carte déjà attribuée »") %}

La carte est déjà associée à un autre étudiant (carte prêtée, erreur précédente). Vérifiez avant de cliquer sur {{ bouton("Attribuer quand même") }} : l'autre étudiant perdra sa carte.

{% endcall %} {% call encadre("astuce", "Carte perdue ou remplacée") %}

Cliquez sur à côté de sa carte (« Retirer la carte »), puis refaites « Scanner la carte » avec la nouvelle. Ses anciens pointages sont conservés.

{% endcall %}

4L'emploi du temps et les émargements

Menu Emploi du temps : la grille de la semaine, importée depuis ADE.

{{ capture("s-edt", "La grille de la semaine d'une classe, avec présents / inscrits sur chaque cours.") }}
  • Choisissez la classe (les CM de la promo sont inclus), filtrez par professeur ou par salle.
  • {{ bouton("Synchroniser l'EDT", "arrow-repeat") }} récupère les changements d'ADE (cours déplacé, prof remplacé). Les présences sont recalculées automatiquement.
  • Un clic sur un cours ouvre sa feuille d'émargement, comme pour le professeur.

5Suivre les absences

Menu Absences : le bilan par classe puis par étudiant, les plus absents en premier.

{{ capture("s-absences", "Le suivi des absences : par classe, puis par étudiant.") }} {% call etape(1, "Choisir la période et la classe") %}

Réglez les dates et la classe, puis {{ bouton("Appliquer") }}.

{% endcall %} {% call etape(2, "Lire le bilan") %}
  • P · R · A : présences, retards, absences. La part justifiée est indiquée à côté.
  • Le symbole compte, pour chaque classe, les étudiants sous {{ SEUIL_RISQUE }} % de présence (hors absences justifiées) ; leur fiche l'affiche en rouge.
  • Un clic sur un étudiant ouvre sa fiche avec tout son historique.
{% endcall %} {% call encadre("astuce", "Quand un étudiant devient-il absent ?") %}

Il est compté absent {{ TOLERANCE_RETARD_MIN }} min après le début du cours s'il n'a pas badgé, et passe en retard s'il badge ensuite. Un cours où personne n'a badgé n'est pas compté (le prof n'avait pas son boîtier).

{% endcall %}

6Justifier une absence

Un étudiant apporte un certificat médical, une convocation… On le saisit sur sa fiche, pour une période.

{% call etape(1, "Ouvrir la fiche de l'étudiant") %}

Depuis la page Étudiants ou Absences, cliquez sur son nom.

{{ capture("s-fiche", "La fiche d'un étudiant : bilan de présence et historique de ses cours.") }} {% endcall %} {% call etape(2, "Saisir la période et le motif") %}

Dans la carte Justificatifs d'absence (sous le bilan), remplissez Du, Au (inclus) et le motif, puis {{ bouton("Justifier les absences de cette période", "check2-square") }}.

{{ capture("s-justificatif", "La carte « Justificatifs d'absence » de la fiche étudiant.") }} {% endcall %} {% call etape(3, "Vérifier") %}

Les absences de ces jours passent en Justifiée dans la fiche, les bilans et les exports. Un retard n'est jamais justifié. Pour annuler, supprimez le justificatif ().

{% endcall %}

7Exporter vers ScoDoc et Excel

{% call etape(1, "Feuille ScoDoc") %}

Page Absences, {{ bouton("Feuille ScoDoc", "file-earmark-arrow-up") }} : choisissez la promo ou le groupe et la semaine, puis {{ bouton("Télécharger") }}. Le fichier contient les absences (ABS) et retards (RET) par demi-journée, au format d'import de ScoDoc.

{{ capture("s-scodoc", "Le menu « Feuille ScoDoc ».") }} {% endcall %} {% call etape(2, "Exports Excel") %}

{{ bouton("Exporter", "download") }} propose la liste des absences (une ligne par absence ou retard) ou le bilan par étudiant. La fiche étudiant et chaque feuille d'émargement ont aussi leur bouton {{ bouton("Excel", "file-earmark-excel") }}.

{% endcall %}

8Retrouver un badge précis

Menu Pointages : la liste brute de tous les badges reçus, avec filtres (étudiant, groupe, enseignement, salle, date et heure). Utile pour répondre à « j'ai pourtant badgé à 8h05 ».

{{ capture("s-pointages", "La liste des pointages filtrable.") }}

9Questions fréquentes

{% call encadre("panne", "Un étudiant badge mais le boîtier fait rouge") %}

Sa carte n'est associée à personne : faites « Scanner la carte » (section 3). Son badge est quand même gardé ; une fois la carte associée, il compte pour les prochains cours.

{% endcall %} {% call encadre("panne", "Un cours est absent de la grille") %}

Cliquez sur « Synchroniser l'EDT ». S'il manque toujours, il n'est pas dans ADE (ou pas dans les semaines importées).

{% endcall %} {% call encadre("panne", "« Session expirée » dans la fenêtre de scan") %}

Vous avez été déconnecté après une longue inactivité : cliquez sur {{ bouton("Se reconnecter") }}.
